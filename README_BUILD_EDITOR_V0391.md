# Build Editor v0.39.1

Исправление карточного редактора и runtime-отрисовки.

## Главное исправление

Раньше `CardData.artwork` одновременно использовался:
- как целая базовая картинка карточки в `CardUI`;
- как внутренняя иллюстрация в Build Editor.

Из-за этого preview и реальная карта расходились.

Теперь введён общий `CardFace`:

```text
CardData
   ↓
CardFace
   ├─ рамка по type
   ├─ artwork как внутренняя иллюстрация
   ├─ название
   ├─ описание
   ├─ стоимость
   └─ УРН / БЛК
```

Один и тот же `CardFace` используется:
- в руке игрока;
- в Deck/Discard Inspector;
- во вкладке «Карты» Build Editor.

Поэтому preview теперь является реальным отображением карты.

## Legacy

Старые карты, где `artwork` указывает на `attack_base.png`,
`defend_base.png` и т. п., продолжают работать.

`CardFace` распознаёт `*_base.png` как старый формат и не пытается
рисовать его внутри окна иллюстрации.

При следующем сохранении карты через редактор legacy base автоматически
перестаёт храниться в `artwork`.

## Адаптивность

Вкладка «Карты» перестроена на два вложенных SplitContainer:

```text
[ список ] | [ preview | форма ]
```

При уменьшении ширины:
- список становится уже;
- preview уменьшается до pixel-perfect 0.5x;
- форма остаётся скроллируемой;
- второстепенная подпись preview скрывается.

При большой ширине preview получает больше места.

Разделители остаются перетаскиваемыми.

## Настройка текста

Для каждой карты отдельно можно менять:

- размер и цвет названия;
- размер и цвет описания;
- размер и цвет стоимости;
- размер и цвет `УРН / БЛК`.

Эти параметры сохраняются в `CardData` и работают в бою.

```text
addons/build_editor/

```

После запуска Output должен показать:

```text
Build Editor 0.39.1 loaded
```
