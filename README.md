# Battle Status UI v0.37

Обновление боевого UI поверх текущего боя.

- отдельные статус-плашки под HP врагов;
- Poison: `ЯД`, стаки и длительность;
- On Fire: `ОГ`, урон тика и длительность;
- Rage: `ЯР`, бонус атаки и длительность;
- Player Shield: `Щ`, уровень I/II/III и длительность;
- Weak: `СЛ`, -25% и длительность;
- tooltip при наведении с подробными значениями;
- статусы больше не дублируются текстом внутри enemy intent;
- если установлен turn-queue patch, активный враг получает подпись `ХОД`;
- никаких новых PNG: UI не создаёт missing-resource ошибок.

## Установка

1. Закрой Godot.
2. Распакуй архив в любое место или просто возьми `apply_battle_status_ui.py`.
3. Положи скрипт в корень проекта рядом с `project.godot`.
4. Запусти:

```powershell
python .\apply_battle_status_ui.py
```

Скрипт создаст backup изменяемых файлов с суффиксом `.bak_before_status_ui`.
