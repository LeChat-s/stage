# Build Editor v0.39.3

Обновлён интерфейс вкладки «Карты».

## Что изменилось

### 1. Больше нет SplitContainer в карточном редакторе

Убраны перетаскиваемые разделители между:

- списком карт;
- preview;
- параметрами карты.

Вместо них используется адаптивная компоновка на `BoxContainer`.

### 2. Адаптивность

Интерфейс автоматически меняется по ширине окна.

**Широкое окно**
```text
[ список ] [ preview ] [ параметры ]
```

**Среднее окно**
```text
[ список ] [ preview
             параметры ]
```

**Узкое окно**
```text
[ список ]
[ preview ]
[ параметры ]
```

На очень широком окне секции параметров раскладываются в две колонки.

Горизонтальная прокрутка формы отключена полностью. Остаётся только обычная
вертикальная прокрутка, когда параметров физически больше высоты окна.

### 3. Детальный просмотр карты

В preview появилась кнопка `Открыть крупно`.

Она открывает `PopupPanel` поверх конструктора и показывает тот же `CardFace`,
который используется в реальной игре.

Доступные масштабы:

- 1×
- 2×
- 3×

Во всех режимах используется `NEAREST`.

Большой preview обновляется в реальном времени при изменении названия,
описания, artwork, цветов и размеров текста.

## Установка

Замени папки из архива поверх проекта:

```text
addons/build_editor/
src/data/cards/
assets/card/
```

После запуска в Output:

```text
Build Editor 0.39.3 loaded
```
