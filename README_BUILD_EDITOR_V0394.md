# Build Editor v0.39.4

UX-переработка вкладки «Карты».

## Главная идея

Preview больше не является отдельной большой колонкой.

Рабочая область теперь:

```text
┌──────────────────┬──────────────────────────────────────────┐
│ маленький preview│  Название карты                Сохранить │
│     106×150      │                                          │
│  открыть крупно  │  ┌────────────┐ ┌────────────┐           │
│                  │  │ Основное   │ │ Бой        │           │
│  список карт     │  └────────────┘ └────────────┘           │
│                  │  ┌────────────┐ ┌────────────┐           │
│                  │  │ Artwork    │ │ Текст      │           │
│                  │  └────────────┘ └────────────┘           │
│                  │  ┌────────────────────────────┐           │
│                  │  │ Effects                    │           │
└──────────────────┴──────────────────────────────────────────┘
```

## Preview

Встроенная карта всегда имеет размер карточки в руке:

```text
106 × 150
```

То есть она больше не растягивается на свободную высоту панели.

Для подробного просмотра используется кнопка со стрелкой `↗`.
Popup по-прежнему поддерживает 1× / 2× / 3× и NEAREST.

## Адаптивность

Широкое окно:
- rail слева;
- две колонки параметров справа.

Среднее окно:
- rail слева;
- одна колонка параметров.

Узкое окно:
- rail становится верхней горизонтальной панелью;
- preview 106×150 слева;
- список карт рядом;
- параметры идут ниже.

Горизонтального scroll у параметров нет.

## Новый визуальный язык

Секции параметров теперь оформлены как компактные editor cards:

- `Основное`;
- `Бой`;
- `Иллюстрация`;
- `Текст`;
- `Эффекты`.

Они используют цвета текущей темы Godot Editor.
Основные текстовые поля собраны в компактные строки `label → control`.

Save/Inspector находятся в закреплённом заголовке рабочей области и не теряются
внизу длинной формы.

## Установка

Замени из архива:

```text
addons/build_editor/
src/data/cards/
assets/card/
```

В Output:

```text
Build Editor 0.39.4 loaded
```
