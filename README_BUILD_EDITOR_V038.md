# Build Editor v0.38.0

UI-обновление конструктора билдов для Godot 4.7.

- Предпросмотр персонажа принудительно использует `TEXTURE_FILTER_NEAREST`.
- Масштаб preview только целочисленный: 1x / 2x / 3x и т.д.
- Добавлено переключение Idle / Attack и пауза.
- Плагин использует новый `EditorDock` Godot 4.7: его можно докать снизу/сбоку или вынести в floating-окно; Godot сам запоминает положение.
- Настройки собраны в `FoldableContainer`.
- Числовые поля заменены на `EditorSpinSlider`, как в Inspector.
- Добавлен поиск по билдам и power score в списке.
- Баланс показывает отдельные индикаторы урона, выживаемости и утилити.
- UI наследует тему и EditorIcons Godot, без собственной жесткой темы.

Установка: замените папку `addons/build_editor` файлами из архива. Формат ресурсов билдов не менялся.
