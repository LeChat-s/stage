# Build Editor v0.39 — встроенный редактор карт

Пакет продолжает v0.38 и добавляет вкладку **«Карты»** в конструктор билдов.

## Шаблоны

Используются исходные пиксельные шаблоны 212×300:

- `assets/card/attack_base.png`
- `assets/card/defend_base.png`
- `assets/card/event_base.png`
- `assets/card/status_effect_base.png`
- `assets/card/contamination_base.png`

Они включены в пакет без изменения размера и отображаются через `NEAREST`.

## Вкладка «Карты»

Слева:

- список карт текущего билда;
- поиск по имени и ID;
- быстрое создание карты одного из пяти типов.

По центру:

- live-preview на реальном шаблоне 212×300;
- название;
- описание;
- стоимость;
- урон / блок;
- пользовательский artwork внутри верхнего окна карты, если это не `*_base.png`.

Справа редактируются реальные поля `CardData`:

- `id`;
- `name`;
- `type`;
- `cost`;
- `dmg`;
- `shild`;
- `damage_type`;
- `target_type`;
- `effect_type`;
- `description`;
- `artwork`;
- принадлежность стартовому пакету билда;
- `effects`.

## Effects

На первом проходе эффекты редактируются как JSON-массив словарей. Это намеренно сохраняет полную совместимость с data-driven системой и не ограничивает редактор известными effect ID.

Пример:

```json
[
  {
    "id": "apply_status",
    "status": "poison",
    "duration": 3,
    "stacks": 2,
    "damage_per_stack": 1
  },
  {
    "id": "gain_build_resource",
    "amount": 1
  }
]
```

Перед сохранением редактор проверяет:

- что корень — массив;
- что каждый элемент — Dictionary;
- что у каждого эффекта есть `id`.

Есть кнопки быстрых заготовок для нескольких часто используемых эффектов.

## Совместимость

Редактор не вводит новый формат карточек: он работает напрямую с существующим `CardData`.

При смене типа карты, если `artwork` был одним из стандартных `*_base.png`, он автоматически меняется на соответствующий новый шаблон. Это сохраняет совместимость с текущим `CardUI`, который пока использует `artwork` как полную текстуру карты.

## Установка

Закрой Godot и распакуй архив в корень проекта с заменой файлов:

```text
project.godot
addons/
assets/
src/
```

Затем открой проект. В Output должно появиться:

```text
Build Editor 0.39.0 loaded
```

Формат `CardData` не менялся.
